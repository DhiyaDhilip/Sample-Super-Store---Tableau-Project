# Sample-Super-Store---Tableau-Project
This Tableau project explores various chart types using a Sample Super Store dataset. It highlights how Tableau helps visualize data through bar charts, pie charts, heat maps, and more. The project reinforces your skills in data analysis, storytelling, and dashboard creation for business insights.


##  Sample Super Store – Tableau Reinforcement Project

###  Project Overview
This project demonstrates the use of **Tableau** for interactive data visualization and dashboard creation. It explores sales, orders, customer demographics, and performance metrics using a sample superstore dataset.

###  Objectives
- Connect to structured sales data
- Create dynamic and interactive visualizations
- Explore business insights across time, category, region, and customer segments
- Reinforce Tableau chart types and dashboard design principles

###  Visualizations Included
- Bar Chart – Compare sales across categories  
- Line Chart – Analyze trends over time  
- Pie Chart – Show proportions of sales or orders  
- Scatter Plot – Explore relationships between variables  
- Histogram – Display distribution of numerical data  
- Gantt Chart – Visualize project timelines or delivery schedules  
- Bubble Chart – Show data concentration across axes  
- Heat Map – Highlight data density and variation  
- Tree Map – Represent hierarchical data visually  
- Box-and-Whisker Plot – Summarize data distribution  
- Area Chart – Show cumulative totals over time  
- Bullet Chart – Compare performance against targets  
- Waterfall Chart – Track cumulative impact of values  
- Packed Bubbles – Cluster data points visually  
- Dual-Axis Chart – Compare two measures on one chart

###  Tools Used
- **Tableau Desktop**  
- **Sample Superstore Dataset**  
- **Calculated Fields, Filters, Parameters, and Dashboard Actions**

###  Outcome
This project reinforces Tableau fundamentals and showcases a wide range of chart types used in business intelligence. It highlights your ability to build clean, interactive dashboards that support data-driven decision-making.
